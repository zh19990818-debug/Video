# 旁白稿（可自行配音，约 90 秒）
1. 【0-8s】在高原与雪山之间，生活着一种体型庞大的野兽——藏马熊。
2. 【8-21s】它是棕熊在青藏高原的亚种，杂食，成年体重可达两百公斤以上。与日本北海道的蝦夷棕熊同属棕熊。
3. 【21-41s】1915年12月，北海道苫前郡三毛别。本该冬眠的棕熊闯入开拓村，数日内造成7人死亡、3人重伤，是日本史上最严重的兽害。最终，猎人山本兵吉将这头体重约340公斤的巨熊击毙。
4. 【41-51s】这并非孤例：1970年福冈大学登山队在日高山脉遇袭；近年山区歉收，熊也更频繁地进入人类生活圈。
5. 【51-65s】熊为什么会伤人？食物不足、突然遭遇、母熊护幼，以及人类留下的食物。多数冲突源于误遇与食物，而非主动猎杀。
6. 【65-83s】遇到熊：结伴并发出声响；不要尖叫奔跑；面向它缓慢后退；携带熊用喷雾；若被扑倒，护住后颈俯卧；食物垃圾密封，绝不投喂。
7. 【83-92s】它们不是怪物，只是野兽。保持距离，就是对彼此最好的尊重。
